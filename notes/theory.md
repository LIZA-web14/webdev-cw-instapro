1. Методы массивов: .map() и .join()
Где мы это делали: на Шаге 1, когда превращали массив постов posts в HTML-разметку.
Что нужно знать:
Метод .map((item) => { return ... }) берёт каждый элемент массива и превращает его во что-то другое (например, объект поста превращает в строку с тегом <li>).
Метод .join("") склеивает массив строк в одну сплошную строку, чтобы её можно было вставить в innerHTML.

2. Шаблонные строки (Template Literals): кавычки ` и ${...}
Где мы это делали: везде, где собирали HTML и ссылки.
Что нужно знать:
Текст внутри косых кавычек `...` может быть многострочным.
Внутрь конструкции ${...} можно вставить любую переменную или выражение JavaScript: ${post.user.name}, ${postsHost}/user-posts/${userId}.

3. Тернарный оператор: условие ? если_да : если_нет
Где мы это делали: когда выбирали, какую иконку лайка показать (красную или прозрачную).
Что нужно знать:
Это короткая запись if / else.
post.isLiked ? "like-active.svg" : "like-not-active.svg" — если лайкнуто, возьми активную картинку, иначе — неактивную.

4. Объекты: доступ к свойствам и деструктуризация
Где мы это делали: post.user.name, { description, imageUrl }.
Что нужно знать:
Вложенные свойства через точку: post → внутри user → внутри name.
Деструктуризация на входе в функцию: вместо function(data) { data.description } пишем сразу function({ description }).

5. Работа с формами и событиями (DOM API)
Где мы это делали: в add-post-page-component.js.
Что нужно знать:
addEventListener("click", () => { ... }) — слушатель клика на кнопку.
inputElement.value — как забрать текст, который напечатал пользователь.
Метод .trim() — удаляет невидимые пробелы в начале и конце строки (защита от пустого ввода).
data-* атрибуты и element.dataset — как положить ID пользователя в HTML (data-user-id) и потом прочитать его в JS (element.dataset.userId).

6. Модули: import и export
Где мы это делали: в самом верху каждого файла.
Что нужно знать:
export — «открывает дверь» для функции или переменной, разрешая другим файлам её использовать.
import { ... } from "./file.js" — берёт готовую функцию из другого файла.
Это нужно, чтобы не писать 3000 строк кода в одном файле, а разбивать проект на аккуратные части.

7. Сетевые запросы: fetch, HTTP-методы и промисы (.then / .catch)
Где мы это делали: в api.js и index.js.
Что нужно знать:
Разница между методами: GET (просто прочитать данные) и POST (сохранить новые данные на сервере).
JSON.stringify(...) — превращение объекта JS в текстовую строку для отправки по проводам интернета.
response.json() — превращение текстового ответа от сервера обратно в объект JS.
.then() — выполняется, когда сервер ответил успешно.
.catch() — перехватывает ошибки (например, если нет интернета).

8. Авторизация: токен и заголовки (headers)
Где мы это делали: Authorization: Bearer <token>.
Что нужно знать:
Сервер не знает, кто сидит перед экраном, пока ты не предъявишь «паспорт» (секретный токен).
Токен передается в служебных заголовках запроса (headers).

9. Колбэки (Callbacks — функции обратного вызова)
Где мы это делали: onAddPostClick, onImageUrlChange.
Что нужно знать:
Главный файл передаёт свою функцию внутрь компонента.
Компонент вызывает её, когда происходит событие (например, юзер нажал кнопку), и передаёт туда введённые данные.
