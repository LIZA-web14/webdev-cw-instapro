# Курсовая работа: Instapro

Аналог социальной сети для обмена фотографиями.

## Реализованная функциональность:
- [x] Авторизация и регистрация пользователей (с сохранением сессии в LocalStorage).
- [x] Динамический рендер постов из API на главной странице.
- [x] Возможность перехода на страницу публикаций конкретного пользователя при клике на его имя/аватар.
- [x] Страница добавления нового поста:
  - компонент загрузки изображения в облако;
  - валидация обязательного наличия текста и фотографии;
  - защита от XSS-уязвимостей (санитизация опасных HTML-символов).
- [x] Функционал лайков:
  - возможность ставить и снимать лайки авторизованным пользователям;
  - динамическое переключение иконки активного/неактивного лайка;
  - счётчик лайков;
  - запрет на лайки для неавторизованных пользователей с уведомлением.

## Оценка времени:
- **Предварительная оценка:** 12 часов.
- **Фактически затраченное время:** 15 часов.

## Дополнительно реализовано:
- Защита от XSS-атак при вводе описания к посту.
- Проверка и обработка ошибок ввода при создании поста.
- Моментальное обновление счетчика лайков без полной перезагрузки страницы браузера.
